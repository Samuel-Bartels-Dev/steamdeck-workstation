# ADR-006: Steam Game Mode Is the Primary Front End

**Status:** Accepted

Steam Game Mode is the unified player-facing launcher. Heroic is used in Desktop Mode for Epic/GOG/Amazon management and adds individual games to Steam. Battle.net is managed through the selected non-Steam launcher workflow and individual supported games are surfaced in Steam. EmuDeck/ES-DE, Moonlight, and chiaki-ng may also be exposed through Steam shortcuts.
