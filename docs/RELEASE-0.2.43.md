# v0.2.43 — Clearer setup completion and retries

A successful retry of one install no longer makes the entire plan look complete
when other selections are unfinished. The setup window shows completed and
attention counts, keeps the running item first, and places items needing attention
ahead of waiting or completed installs. Guided account setup retains its own result.

Appearance options for tools that are not selected are labelled as preferences
only. The install button now says Installing while an operation is running.

See [sharing and resuming setup](setup/SHARING-AND-RESUME.md) for the handoff flow.
