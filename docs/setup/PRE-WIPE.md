# Pre-Wipe Checklist

Before resetting the existing Deck, preserve only the state that is difficult or impossible to recreate.

## Critical

- Confirm Steam Cloud status for games you care about; do not assume every game uses it.
- Copy emulator saves and save states from your current EmuDeck install.
- Copy any non-cloud PC game saves you care about.
- If WoW is installed, copy `WTF/` and `Interface/AddOns/` for UI/addon configuration.
- Preserve any legal BIOS/firmware dumps in a separate private location.
- Preserve ROM/game backups separately from this repository.
- Record/backup any custom controller layouts or game-specific settings that are not synced by Steam.

## Useful reference

- Note which microSD card contains which library.
- Note your Sunshine host names and the MAC address of any PC you want to wake remotely.
- Make sure you can authenticate to Steam, Epic, Battle.net, PSN, Tailscale, and ChatGPT/Codex after the wipe.
- Have this v0.2.36 USB bundle available before starting the reset.

## Do not copy into Git

Credentials, browser cookies, SSH private keys, PSN/Tailscale tokens, BIOS/firmware binaries, ROMs, and personal saves remain private data.
