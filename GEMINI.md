# Gemini CLI Entry Point

Use the repository as the source of truth.

Read:
- `docs/PRINCIPLES.md`
- `docs/ai/COMMON.md`
- the active task under `tasks/active/`, if present
- the target module's `README.md` and `module.json`

Do not broaden scope automatically. Validate with `./bin/deckctl repo validate` and module tests.
